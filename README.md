# Космический Вова / Cosmic Vova

Завершённая браузерная игра в жанре космического пинбола. Реализованы поле 4:3, Matter.js-физика, четыре флиппера, пусковая пружина, три метеорита, очки, серии попаданий, цели, бонусный режим Cosmic Vova, интерфейс RU/EN, анимированный персонаж Вова и оригинальный процедурный chiptune-звук.

Играть: [nikitaapenkin.github.io/vova](https://nikitaapenkin.github.io/vova/)

## Управление

- `A` или `←` — оба левых флиппера
- `D` или `→` — оба правых флиппера
- удерживать `Space`, затем отпустить — запуск метеорита
- `Enter` — начать игру
- `P` или `Esc` — пауза
- `L` — переключить RU/EN
- `M` — включить или выключить звук
- `R` — новая партия после Game Over

Язык, настройка звука и лучший результат сохраняются в `localStorage`.

Музыка и звуковые эффекты синтезируются в браузере через Web Audio API. Аудиофайлы и сторонние музыкальные материалы не используются.

## Разработка

```bash
pnpm install
pnpm dev
pnpm lint
pnpm test
pnpm build
```

Vite настроен для публикации по пути `/vova/`. Персонаж в `public/assets/character/vova-sprites.png` создан специально для проекта встроенным генератором изображений OpenAI по предоставленной пользователем фотографии-референсу. Исходная фотография в сборку не включена. Остальная графика программно нарисована в Phaser; сторонние игровые ассеты не используются.
